# Python-Retail-Sales-Analysis
Retail Sales Data Analysis using Python with Pandas for data cleaning, data exploration, and category-wise sales analysis.
# Retail Sales Analysis using Python

## Project Overview
This project analyzes retail sales data using Python to understand sales performance and category-wise sales distribution.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Work Done
- Imported the retail sales dataset.
- Explored the dataset using df.info() and df.dtypes.
- Checked column names and data types.
- Grouped sales data by product category.
- Calculated total sales for each category.
- Compared sales performance across categories.

## Objective
The objective of this project is to clean, explore, and analyze retail sales data using Python.

## Outcome
The analysis helps identify which product categories contribute to overall sales and supports better understanding of sales data.
